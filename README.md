\## Project Overview



This repository has a detailed audit of VLC Media Player and five Linux shell scripts that show system administration and automation skills. The scripts are designed to work to give a complete picture of the system.



\## The 5 Scripts



1\. \*\*System\_identity.sh\*\*: This script creates a screen with information about the operating system and license. It is a way to get started with the audit.



2\. \*\*Package\_inspector.sh\*\*: This script checks if VLC Media Player is installed on the system and prints out its philosophy. It is useful to know if the software is installed and what it does.



3\. \*\*Disk\_auditor.sh\*\*: This script audits the permissions and size of system directories. It helps to identify any security risks or issues with the system.



4\. \*\*Log\_analyzer.sh\*\*: This script scans log files for keywords like ERROR or WARNING. It is helpful to identify any problems with the system and fix them.



5\. \*\*Manifesto\_gen.sh\*\*: This is a script that generates a personal open source software manifesto. It is a way to express your thoughts and ideas about open source software.



\## How to Run



1\. First you need to clone the repository:



`git clone https://github.com/johndoe/oss-audit-RD1234.git`



2\. Then navigate to the folder:



`cd oss-audit-RD1234`



3\. Next give execution permissions:



`chmod +x \*.sh`



4\. Finally run a script for example the script:



`./system\_identity.sh`



\## Dependencies



\* You need a Linux environment and Ubuntu or CentOS is recommended.



\* You need `rpm` or `dpkg` package managers.



\* You also need utilities, like `awk` `grep` `du` and `uptime`. These are tools that are necessary for the scripts to work.
