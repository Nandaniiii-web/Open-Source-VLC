## Project Overview
This repository contains a structured audit of VLC Media Player and a suite of five Linux shell scripts designed to demonstrate system administration and automation skills.

## The 5 Scripts
1. **system_identity.sh**: Generates a welcome screen with OS and license info.
2. **package_inspector.sh**: Checks if VLC Media Player is installed and prints its philosophy.
3. **disk_auditor.sh**: Audits permissions and size of key system directories.
4. **log_analyzer.sh**: Scans log files for specific keywords (e.g., ERROR/WARNING).
5. **manifesto_gen.sh**: Interactive script that generates a personal OSS manifesto.

## How to Run
1. Clone the repository:
   `git clone https://github.com/Nandaniiii-web/Open-Source-VLC.git`
2. Navigate to the folder:
   `cd oss_project_24BCE10775`
4. Give execution permissions:
   `chmod +x *.sh`
5. Run a script (e.g., Script 1):
   `./script1.sh`

## Dependencies
* A Linux environment (Ubuntu/CentOS recommended).
* `rpm` or `dpkg` package managers.
* Standard utilities: `awk`, `grep`, `du`, `uptime`.
